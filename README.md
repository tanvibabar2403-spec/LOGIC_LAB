# LogicLab — Digital Logic Gate Simulator

LogicLab is a web-based mini project developed as part of **Digital Electronics and Computer Organization (DECO)**. It provides an interactive way to explore basic digital logic gates and understand how binary inputs produce outputs.

The project is built using HTML, CSS, and vanilla JavaScript.

## 🚀 Current Features

- **Homepage:** A starting page introducing the LogicLab project.
- **Interactive Logic Gate Simulator:** Experiment with different logic gates by changing binary inputs.
- **Seven Logic Gates:** Supports AND, OR, NOT, NAND, NOR, XOR, and XNOR.
- **Real-Time Output:** The output updates automatically when inputs or the selected gate change.
- **Truth Table Generator:** Displays the truth table for the selected logic gate.
- **Active Row Highlighting:** Highlights the truth table row corresponding to the current input combination.
- **CSV Export:** Download the generated truth table as a CSV file for further use.

## 🛠️ Technologies Used

- HTML5 — webpage structure
- CSS3 — styling and responsive layout
- JavaScript — logic calculations and interactive functionality

## ▶️ How to Run

No installation or build tools are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Navigate to the simulator.
5. Select a logic gate and change the inputs to observe the output and truth table.
